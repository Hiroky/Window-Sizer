# Window Sizer

指定したウインドウの**クライアント領域**（枠・タイトルバー・メニューバーを除いた内側）を、指定したピクセル数に変更する Windows 用ツールです。

## 機能

- 表示中のウインドウを一覧表示（タイトル / プロセス名 / 現在のクライアント幅・高さ）
- 一覧で各ウインドウの現在のクライアントサイズを確認できる（選んでも入力欄は変わらない）
- 一般的な解像度（VGA〜8K UHD の 22 種類）のプリセットから選択可能。手入力の値に一致すればプリセット欄も連動
- 幅・高さを指定して「適用」（Enter キーでも可）
- 最小化・最大化中のウインドウは、通常状態に戻してから適用
- 適用後の実際のサイズを表示。アプリ側の最小・最大サイズ制限で変わった場合は警告

## 動作環境

- Windows 10 / 11（動作確認は Windows 11）
- 実行: .NET 10 Desktop Runtime
- ビルド: .NET 10 SDK

## 使い方

1. `WindowSizer.exe` を起動する
2. 一覧から対象のウインドウを選ぶ（一覧に無い場合は「一覧を更新」）
3. 解像度プリセットから選ぶか、幅と高さ（クライアント領域の px）を直接入力する
4. 「適用」を押す

## ビルドと実行

プロジェクトフォルダで実行します。

```bash
dotnet run
```

単体の exe を作る場合:

```bash
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

出力先: `bin\Release\net10.0-windows\win-x64\publish\WindowSizer.exe`

## 仕組み

- `GetWindowRect`（枠を含む外側の矩形）と `GetClientRect`（クライアント領域）の差が、タイトルバー・枠線・メニューバーなどの大きさになります。
- 要求されたクライアントサイズにこの差を足した外側サイズを `SetWindowPos` で設定します。
- 本アプリは DPI 対応（PerMonitorV2）で動作し、数値は物理ピクセルで扱います。
- 位置（左上座標）は変えず、サイズだけを変更します。

## 注意事項

- アプリ自身が定めた最小・最大サイズ（`WM_GETMINMAXINFO`）より小さく、または大きくはできません。その場合は実際のサイズが画面に表示されます。
- 管理者権限で動いているウインドウを変更するには、本アプリも管理者として起動する必要がある場合があります。
- 別の仮想デスクトップ上にあるウインドウは一覧に表示されません。
- 本アプリ自身のウインドウは一覧から除外しています。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `Program.cs` | エントリーポイント・DPI 設定 |
| `MainForm.cs` | 画面（一覧・プリセット欄・入力欄・適用ボタン） |
| `DisplayPreset.cs` | 解像度プリセットの一覧 |
| `WindowResizer.cs` | ウインドウの列挙とサイズ変更 |
| `NativeMethods.cs` | Win32 API の宣言 |
